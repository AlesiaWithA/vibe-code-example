# vibe-code-challenge

Static single-page Valentine site (picture, Yes/No buttons, sparkles, hearts).

## GitHub Pages

1. **Push to GitHub** (if not yet):
   ```bash
   git add .
   git commit -m "Prepare for GitHub Pages"
   git push origin main
   ```

2. **Enable Pages** in the repo:
   - **Settings** → **Pages**
   - **Source**: Deploy from a branch
   - **Branch**: `main` (or `master`) → folder **/ (root)** → Save

3. **URL** (after a couple of minutes):
   - `https://<username>.github.io/vibe-code-challenge/`

`.nojekyll` in the root disables Jekyll so the site is served as plain static files.
